Analisi Dati: Dataset 1000-righe (Python)

Mini-framework Python per il caricamento, pulizia, analisi e visualizzazione di un dataset da 1000 righe. Architettura modulare con: DataLoader, DataCleaner, DataAnalyzer, DataVisualizer, DataExporter, Predictor.

Stack: Python • pandas • matplotlib
Files: data_loader, data_cleaner, data_analyzer, data_visualizer, data_exporter, predictor, main
Dataset: 1000 righe, valori misti (numerici & categorici)
Output: grafici PNG, CSV pulito, analisi

Spiegazione tecnica dettagliata

Il progetto è organizzato in moduli Python, ciascuno con responsabilità chiare. Questo garantisce facilità di testing, riusabilità e chiarezza architetturale. Di seguito una descrizione per file con snippet esemplificativi.

data_loader.py — Caricamento dati

Responsabilità: caricare CSV (o sorgenti future), normalizzare dtypes.

# Esempio d'uso (snippet)
from data_loader import DataLoader

path = input("\nInserisci il percorso del file CSV: ")

loader = DataLoader(path)
df = loader.load_data()

if loader.is_loaded():
print("\nDataset caricato correttamente!")
loader.show_head()

Note: sempre usare con try/except se integrato in pipeline più ampia.

data_cleaner.py — Pulizia e preprocessing

Responsabilità: pulizia dei tipi di dato, riempimento valori vuoti, rimozione duplicati, rimozione valori negativi, rimozione valori NaN.

# Esempio d'uso (snippet)
from data_cleaner import DataCleaner

cleaner = DataCleaner(df)
df = cleaner.clean_data_types()
df = cleaner.fill_missing_values()
df = cleaner.remove_duplicates()
df = cleaner.remove_negatives_values()
df = cleaner.remove_unknown_values()
df = cleaner.full_clean()
cleaner.summary()

data_analyzer.py — Statistiche & aggregazioni

Responsabilità: descrizione statistica, analisi valori vuoti, analisi dtypes, correlazioni, medie....

# Esempio d'uso (snippet)
from data_analyzer import DataAnalyzer

print(analyzer.get_description())
print(analyzer.get_missing_values())
print(analyzer.get_dtypes())
print(analyzer.get_correlations())
print(analyzer.complete_analysis())
print(analyzer.get_mean_by_gender())
print(analyzer.get_usage_by_gender())
print(analyzer.get_top_locations())

data_visualizer.py — Visualizzazioni

Responsabilità: plotting delle analisi eseguite; istogrammi, trend o heatmap.

# Esempio d'uso (snippet)
from data_visualizer import DataVisualizer

visualizer = DataVisualizer(df)
fig = visualizer.plot_distribution(col)
fig = visualizer.plot_correlation_matrix()
fig = visualizer.plot_missing_values()
fig = visualizer.plot_gender_comparison(col)
top = DataAnalyzer(df).get_top_locations()
fig = visualizer.plot_top_location(top)
col2 = input("Seconda colonna: ")
fig = visualizer.plot_scatter(col, col2)

data_exporter.py — Esportazione risultati

Responsabilità: esportazione delle analisi in .json, .txt o .png.

# Esempio d'uso (snippet)
from data_exporter import DataExporter

exporter = DataExporter(df)
filename = input("Nome file (esempio: grafico.jpeg): ")
exporter.save_figure(fig, filename)
exporter.export_to_json()
exporter.export_to_txt()
exporter.export_analysis_to_json(DataAnalyzer(df).complete_analysis())

predictor.py — Modello predittivo minimale

Responsabilità: pipeline di training (scikit-learn), predizioni batch.

# Esempio d'uso (snippet)
from predictor import Predictor

predictor = SimplePredictor(df)
predictor.train()
x = float(input("\nInserisci valore per la predizione dell'età: "))
print("Età predetta:", predictor.predict_age(x))

main.py — Pipeline orchestrator

Responsabilità: punto d'entrata; costruisce pipeline (load→clean→analyze→viz→export→predict).

# main.py (semplificato)
from data_loader import DataLoader
from data_cleaner import DataCleaner
from data_analyzer import DataAnalyzer
from data_visualizer import DataVisualizer
from data_exporter import DataExporter
from predictor import SimplePredictor

def main():
    loader = DataLoader()
    cleaner = None
    analyzer = None
    visualizer = None
    exporter = None
    predictor = None

if __name__ == "__main__":
    main()

Strumenti & Requisiti

  • Python 3.10+
  • pandas (manipolazione dati)
  • matplotlib (visualizzazione)
  • scikit-learn (sezione predictor)
  • joblib (serializzazione modelli)

Esempio: flusso completo

# Flusso ridotto
df = DataLoader("data/raw/dataset.csv").load_csv()
df_clean = DataCleaner(df).run_all()
summary = DataAnalyzer(df_clean).describe_all()
DataVisualizer(df_clean).plot_distribution("age")
DataExporter(df_clean).to_csv("data/clean/dataset_clean.csv")
